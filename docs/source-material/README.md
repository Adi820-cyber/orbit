# Orbit source-material policy

The Orbit specifications were researched against the supplied KPI workbook and pitch export, but those source artifacts are intentionally **not copied into this repository**. The repository rules prohibit committing sensitive/client source spreadsheets, presentations, credentials, or real operational records, even when the repository is private.

When a source-backed claim must be rechecked:

1. Obtain the approved artifact through the project owner or an approved secure workspace.
2. Keep it outside Git, or place it in an explicitly approved ignored path.
3. Record only the verified conclusion, source name, sheet/page, and date in the relevant specification or decision record.
4. Do not upload the artifact, its extracted records, credentials, or screenshots containing sensitive data.

The current specifications identify the expected source names and the claims that were verified. Any future implementation must label source claims as verified, proposed, or assumed rather than treating this note as proof that the source is present.
